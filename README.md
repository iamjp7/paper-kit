# PaperKit

Client-side PDF editor. Edit text, compress images, merge files, and delete pages in the browser. Files are not uploaded.

## Run

```bash
cd /Users/jayprakash/Desktop/Project/paper-kit
npm install
npm run dev
```

Open http://localhost:5173/edit (or the URL shown in the terminal).

## Logo

The PaperKit mark combines stacked pages (kit) with a document and check badge — your PDF toolkit in the browser.
